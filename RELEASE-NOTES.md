# ClipForge 0.1.0

First public preview of ClipForge for Windows.

- Turn local video and supported live links into short MP4 clips.
- Export vertical clips with animated word-by-word captions and editable SRT files.
- Preview, save, or reject clips in the app.
- Process on the local CPU, a compatible NVIDIA GPU, or a configured remote worker.

Twitch was tested end to end. YouTube Live capture was verified separately. Live Kick playback still needs testing. Clip selection is based on speech cues, and captions and framing should be reviewed before sharing.

This release contains source code. See the README for Windows setup, known limitations, and content and privacy guidance.
